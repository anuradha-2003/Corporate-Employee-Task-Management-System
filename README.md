# Corporate Employee Task & Productivity Management System

## Project Overview
The Corporate Employee Task & Productivity Management System is a web-based application developed using the MERN stack. It helps employees manage their daily tasks, track progress, set priorities, and monitor deadlines.

## Technologies Used
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Token)
- **API Communication:** Axios

## Key Features
- User Registration and Login
- Secure Authentication
- Protected Dashboard
- Create, View, Update, and Delete Tasks
- Task Priority Management
- Task Status Management
- Deadline Management
- Dashboard Statistics
- Pending, In Progress, Completed, and Overdue Task Tracking
- Logout Functionality

## Installation and Setup

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install Backend Dependencies
```bash
cd server
npm install
```

### 3. Configure Environment Variables
Create a `.env` file inside the `server` folder and configure your MongoDB connection string, JWT secret, and port according to your backend code.

**Important:** Do not upload your `.env` file or database credentials to GitHub.

### 4. Start the Backend
```bash
npm start
```

### 5. Install Frontend Dependencies
Open another terminal:
```bash
cd client
npm install
```

### 6. Start the Frontend
```bash
npm run dev
```

## Application URLs
- Frontend: `http://localhost:5173`
